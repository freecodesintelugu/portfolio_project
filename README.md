# 🚀 DevOps Portfolio Website

This project is a personal portfolio website designed to showcase my DevOps and Cloud skills, projects, and tools. It is built as a static website and deployed using AWS services for high availability, performance, and scalability.

---

## 🌐 Architecture

User → Route 53 → CloudFront → S3

- Amazon S3 stores static website files
- CloudFront provides CDN and HTTPS
- Route 53 manages custom domain and DNS routing

---

## 🛠️ Technologies Used

### Cloud:
- AWS S3

- AWS Route 53

### DevOps Tools:
- AWS
- Docker
- Kubernetes
- Terraform
- GitHub
- Linux
- Monitoring tools (Prometheus, Grafana)

### Frontend:
- HTML
- CSS
- JavaScript

---

## ✨ Features

- Responsive and modern UI (dark theme)
- Profile section with resume download
- Projects section with video demonstrations
- DevOps tools showcase with icons
- Smooth scrolling and animations
- Optimized for fast loading via CDN
